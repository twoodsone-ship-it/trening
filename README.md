# IronForge PWA: Умный Трекер Прогрессии Нагрузок 🏋️‍♂️⚡

> Современное прогрессивное веб-приложение (PWA) для силового тренинга в тренажерном зале с автономной математической моделью **Smart Double Progression (Умная Двойная Прогрессия)**, таймером отдыха на Web Audio API, калькулятором блинов и полным сохранением данных без интернета.

---

## 🌟 Ключевые возможности

### 1. Алгоритм Умной Двойной Прогрессии (Smart Double Progression)
Классическая двойная прогрессия заставляет атлета топтаться на месте или делать опасные скачки веса при грязной технике. IronForge решает это алгоритмически:
- **Автоматический переход по диапазону**: Сначала атлет наращивает повторения внутри целевого диапазона (например, от $3 \times 8$ до $3 \times 12$).
- **Анализ RPE / Запаса сил**:
  - При закрытии всех $3 \times 12$ с $\text{RPE} \le 8.5$: система инициирует **⚡ Повышение веса** ($+\Delta W$, например $+2.5\text{ кг}$) и сбрасывает повторы на нижнюю границу ($3 \times 8$).
  - При закрытии на пределе сил ($\text{RPE} \ge 9.5 - 10$): система рекомендует **🔄 Закрепление веса** еще на одну тренировку для стабилизации техники.
- **Детектор плато (Plateau Detection)**:
  - Если за 3 тренировки подряд результат не растет, система выдает предупреждение с выбором: **Микро-прибавка** ($+0.5 / +1\text{ кг}$) либо **Делоад** ($-10\%$ веса на 1 сессию).
- **Расчет 1RM**: Расчет предельного одноповторного максимума по формулам Эпли и Бжицки:
  $$\text{1RM} = \frac{w \cdot (1 + r/30) + w \cdot \frac{36}{37 - r}}{2}$$

### 2. Эргономика для зала (Gym Mobile UX)
- **High-contrast OLED Dark Theme**: Полностью черный фон (`#0a0a0c`) с изумрудными акцентами, минимальное энергопотребление экрана в зале.
- **Ghost Data**: В каждом подходе серым цветом отображаются фактические показатели с прошлой тренировки (`Пред: 12 × 75 кг`).
- **Степперы под большой палец**: Быстрое изменение веса и повторений кнопками `+` и `-` с заданным шагом.
- **Таймер отдыха**:
  - Сгенерирован на чистом **Web Audio API** (не требует скачивания mp3, 100% офлайн).
  - Предупреждающие сигналы за 3, 2, 1 секунду + финальный триумфальный гонг.
  - **Haptic Vibration API**: телефон завибрирует в кармане, когда пора идти на следующий подход.
  - Кнопки быстрой коррекции: `+30с`, `-15с`, минимизация в компактный плавающий индикатор.
- **Калькулятор блинов (Plate Calculator)**:
  - Автоматический расчет навески на олимпийский гриф 20 кг (или 15/10 кг) для любого веса.
  - Визуальная цветная схема дисков (25, 20, 15, 10, 5, 2.5, 1.25, 0.5 кг).

### 3. PWA & Офлайн надежность
- Работает полностью без интернета в подвальных залах благодаря Service Worker и Cache API.
- Устанавливается как нативное приложение на iOS (Safari: *Поделиться -> На экран «Домой»*) и Android (*Установить приложение*).
- Автоматический экспорт и импорт полной базы данных в формате JSON.

## 🚀 Деплой на GitHub Pages

Проект подготовлен для нулевой конфигурации при публикации на GitHub Pages:
- Относительные пути ассетов в сборке (`base: './'` в `vite.config.ts`).
- Готовый GitHub Actions workflow в `.github/workflows/deploy.yml`.

### Активация на GitHub:
1. Создайте репозиторий на GitHub (например, `trening` или `ironforge-pwa`).
2. Привяжите удаленный репозиторий:
   ```bash
   git remote add origin https://github.com/<ВАШ_НИКНЕЙМ>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings -> Pages**:
   - В разделе **Source** выберите **GitHub Actions**.
4. Workflow автоматически соберет проект и развернет его по адресу:
   ```
   https://<ВАШ_НИКНЕЙМ>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/
   ```

## 💻 Локальный запуск и тестирование

```bash
# Установка зависимостей
npm install

# Запуск модульных тестов алгоритма прогрессии
node --experimental-strip-types test-progression.ts

# Запуск локального сервера разработки
npm run dev

# Сборка продакшн PWA
npm run build

# Предпросмотр продакшн сборки
npm run preview
```
