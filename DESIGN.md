# IronForge interface direction

## Product

IronForge is a mobile-first workout log used between sets, often with one hand and limited attention. The interface should make the next useful action obvious, keep training controls readable at a glance, and keep advice tied to the selected exercise.

## Visual thesis

Treat the app like a precise training journal: dark graphite surfaces, clear dividers, large condensed workout headings, monospaced measurements, and lime reserved for the next action or measurable progress. Use open lists and compact data rows where they clarify the plan. Use panels only to group a real task or state.

## Tokens

- Background: `#090b0a`
- Raised surface: `#121614`
- Elevated surface: `#1b211e`
- Primary text: `#f2f5f1`
- Secondary text: `#a2aca4`
- Action / progress: `#c8f542`
- Display type: Barlow Condensed
- Interface type: DM Sans
- Measurements: JetBrains Mono

## Interaction rules

- Touch controls are at least 48px and remain clear of safe areas and fixed navigation.
- Workout screens prioritize the current set, timer, and exact exercise guidance.
- Never substitute a different exercise's technique or animation when a specific guide is unavailable; show neutral, accurate instructions instead.
- Use animation only when it explains state or movement; respect reduced-motion preferences.
- Preserve saved programs, workout history, and active sessions during visual changes.
